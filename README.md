# 📝 TODO Uygulaması - React & JavaScript

Modern bir TODO uygulaması. CRUD (Create, Read, Update, Delete) işlemlerini içerir.

## 🚀 Özellikler

- ✅ **CREATE** - Yeni görev ekleme
- 📋 **READ** - Görevleri listeleme
- ✏️ **UPDATE** - Görev güncelleme
- 🗑️ **DELETE** - Görev silme
- ✔️ Görev tamamlama/tamamlamayı geri alma
- 💾 LocalStorage ile veri saklama
- 🎨 Tailwind CSS ile modern tasarım
- 📱 Responsive tasarım

## 🛠️ Kullanılan Teknolojiler

- React 18
- JavaScript (ES6+)
- Tailwind CSS
- LocalStorage API

## 📦 Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm start

# Production build oluştur
npm run build
```

## 📁 Proje Yapısı

```
src/
├── Components/
│   ├── TodoForm.jsx    # Görev ekleme/güncelleme formu
│   ├── TodoItem.jsx    # Tekil görev bileşeni
│   └── TodoList.jsx    # Görev listesi bileşeni
├── Pages/
│   └── TodoPage.jsx    # Ana sayfa ve state yönetimi
├── Interfaces/
├── App.js
└── index.css
```
